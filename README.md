# Pizza Courier (Console RPG)

Консольная игра-новелла с элементами RPG, написанная на Python. Вы играете за курьера, которому нужно доставить пиццу в опасный район, управляя деньгами, кармой и временем.

## 🚀 Технические особенности (Highlights)
* **ООП-архитектура**: Игровые сущности и состояние инкапсулированы в классах.
* **Конечный автомат (State Machine)**: Чистое переключение между сценами (Меню, Игра, Карта, Катсцены).
* **Слоистая отрисовка**: Рендеринг ASCII-графики в терминале с помощью 3D-матриц (Z-index для наложения фонов и UI).
* **Управление состоянием**: Передача контекста игрока между сценами без глобальных переменных.

## 🛠 Стек
* Python 3.11+
* Nix (для воспроизводимого окружения `shell.nix`)
* Git

## 🎮 Геймплей
* Передвижение по карте и выбор маршрута.
* Система диалогов (в разработке).
* Взаимодействие с NPC и система кармы (в разработке).
